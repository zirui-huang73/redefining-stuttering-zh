# 《重新定义口吃》中文阅读网站设计

## 目标

将现有书前内容、65 篇正文与术语表制作成可免费部署的静态阅读网站。桌面端使用章节侧栏，移动端使用抽屉导航，并提供上一篇／下一篇、深色模式和三级字号。

## 技术方案

- Astro 静态生成，不使用服务器、数据库或付费 API。
- Cloudflare Pages 托管 `dist` 构建产物。
- Markdown 译稿是唯一正文来源。
- 构建前脚本扫描上级译稿目录，检查章节完整性，渲染 Markdown，并复制书中图片。
- 页面网址稳定为 `/chapters/01/` 至 `/chapters/65/`，书前内容与术语表使用具名网址。

## 界面

- 温润纸书风，使用系统自带中文宋体与无衬线字体，不加载外部字体。
- 固定书籍页眉、按八部分分组的章节侧栏、正文阅读区和长文页内目录。
- 手机端侧栏改为抽屉。
- 深浅主题与字号选择仅保存在浏览器本地，不使用 Cookie 或分析服务。

## 内容与安全

- 书中原始绝对图片路径在构建时改写为站内路径。
- 外部链接在新窗口打开，并附加安全的 `rel` 属性。
- 仅渲染受信任的本地译稿。
- Cloudflare 响应头关闭内容嗅探和不必要的跨站来源信息。

## 验证

- 检查书前内容、01–65 篇正文与术语表全部存在。
- 拒绝重复编号、空标题和缺失图片。
- 生产构建后检查所有静态章节路由、首页、404 页面及关键资源。
- 检查脚注、表格、侧栏链接、前后章导航和移动端布局。
